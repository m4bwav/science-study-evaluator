# Changelog: science-study-evaluator

Every change to [SKILL.md](SKILL.md), the references, the script and the companions, newest first, each with the reason. Reasons cite findings in [RESEARCH.md](RESEARCH.md) (`R-`), lessons in [LEARNINGS.md](LEARNINGS.md) (`L-`) and test runs in [TESTS.md](TESTS.md) (`T-`). State in `evergreen.json`. Protocol: MAINTENANCE.md.

Entry shape: `### C-YYYYMMDD-n · date · one-line summary`, then `because:` (IDs or "user request"), `files:` (file and section), and a sentence on what changed. Cite section headings, not line numbers.

### C-20261011-1 · 2026-10-11 · 0.1.0: first public release
- because: user request (publish the skill for anyone to install, modernised); L-002, L-009
- files: everything
- The skill had run privately since 2026-08-31 on one machine and one app, with its checklist at methodology v7. This release makes it portable. SKILL.md drops machine paths and app-specific tools and works in any agent that reads skills; appraisals and the verdict log moved to a user folder (`SSE_HOME`, default `~/.science-study-evaluator/`) with an optional `reader.md` describing who reads the reviews. The steps were reorganised into source, appraise, write, keep. The retrieval lessons became `references/fetch-routes.md`, and the glossary and analogies `references/explaining.md`. `paper_meta.py` was rewritten: argparse, `--json`, PMID and PMCID input and DOIs pulled out of publisher URLs, contact email from `--email` or `SSE_EMAIL` instead of a hard-coded address (Unpaywall is skipped without one), NCBI tool, email and API-key parameters, UTF-8 output on Windows without an environment variable, Crossref `updated-by` notices including Retraction Watch, PubMed retraction and erratum links, an INTEGRITY NOTICE in NEXT, and `--fulltext DIR`, which saves the Europe PMC article as XML and as greppable text. Added offline unit tests, CI on three operating systems, and eval cases.
- History before publication (private ids): methodology v1 2026-08-31 (baseline: CONSORT 2025, ROBINS-I v2, GRADE Book, paper-mill tools); v2 2026-09-02 (qualitative branch, sample recycling, retracted load-bearing citations); v3 2026-09-15 (composite exposures, observational-regression branch, attrition, omission as spin, publication-status drift); v4 2026-09-16 (single-arm pre/post branch and hold-out outcome, recency mirror check); v5 2026-09-28 (umbrella reviews, sibling comparisons and negative-control exposures, "not linked" as spin); v6 2026-09-30 (equivalence and non-inferiority margins, sponsored-trial comparators, Retraction Watch via Crossref); v7 2026-10-01 (coarse controls, ability exposures, single-item outcomes, the hop that added the claim). The methodology's own Changelog section has the detail.
